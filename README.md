# Lead Recovery Dashboard

Public dashboard page for the Software Finder lead recovery monitor. It shows totals only: no lead names, company names or Record IDs.

- `index.html`, `app.js`, `app.css`: the page.
- `data.json`: the totals the page reads, refreshed by the monitor. The page reloads it every 5 minutes.

Lead activity and Record ID search are in the private copy, which is not published.
